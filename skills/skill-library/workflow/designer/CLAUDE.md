# Designer Workflow

> 출처: [pbakaus/impeccable](https://github.com/pbakaus/impeccable)
> 이 워크플로우를 프로젝트의 `.claude/` 디렉토리에 복사하면 디자이너 중심의 AI 환경이 구성됩니다.

## 핵심 원칙

- **의도적 디자인**: 대담한 미니멀리즘이든 세련된 맥시멀리즘이든, 핵심은 의도성이다
- **제네릭 탈피**: Inter 폰트, 보라색 그라디언트, 회색 텍스트 같은 "AI 느낌" 디자인을 거부한다
- **프로덕션 품질**: 프로토타입이 아닌, 실제 출시 가능한 수준의 코드를 작성한다
- **디자인 컨텍스트 필수**: 프로젝트 컨텍스트 없이 디자인하지 않는다

## 디자인 컨텍스트 수집 (필수)

모든 디자인 작업 전에 반드시 확인한다:

1. **현재 지시사항 확인**: 이미 Design Context 섹션이 있는지 확인
2. **`.impeccable.md` 확인**: 프로젝트 루트에 이 파일이 있으면 참조
3. **`/teach-impeccable` 실행**: 위 두 곳에 없으면 반드시 컨텍스트 수집을 먼저 실행

필수 컨텍스트:
- **대상 사용자**: 누가 이 제품을 어떤 상황에서 사용하는가?
- **사용 사례**: 어떤 작업을 수행하려 하는가?
- **브랜드 성격/톤**: 인터페이스가 어떤 느낌이어야 하는가?

## 디자인 방향 설정

모든 인터페이스에 **과감한 미적 방향**을 설정한다:

- **목적**: 이 인터페이스가 해결하는 문제는?
- **톤**: 극단적 선택 - brutally minimal, maximalist chaos, retro-futuristic, organic/natural, luxury/refined, playful/toy-like, editorial/magazine, brutalist/raw, art deco/geometric, soft/pastel, industrial/utilitarian
- **제약**: 기술적 요구사항 (프레임워크, 성능, 접근성)
- **차별화**: 무엇이 이 디자인을 잊을 수 없게 만드는가?

## 7대 디자인 도메인

### 1. 타이포그래피
- 5단계 시스템: xs, sm, base, lg, xl+ (더 적은 크기, 더 큰 대비)
- 모듈러 스케일: 1.25(장3도), 1.333(완전4도), 1.5(완전5도)
- 수직 리듬: line-height를 기본 단위로 모든 수직 간격 설정
- **피해야 할 폰트**: Inter, Roboto, Open Sans, Lato, Montserrat (너무 흔함)
- **대안**: Instrument Sans, Plus Jakarta Sans, Outfit, Onest, Figtree

### 2. 색상과 대비
- **OKLCH 사용** (HSL 사용 금지): 지각적으로 균일한 색상 공간
- **틴티드 뉴트럴**: 순수 회색 대신 브랜드 색조를 미세하게 추가
- **60-30-10 규칙**: 60% 중립, 30% 보조, 10% 강조
- **접근성**: 본문 4.5:1, 큰 텍스트 3:1, UI 컴포넌트 3:1

### 3. 공간 디자인
- 간격 시스템, 그리드, 시각적 계층
- 일관된 spacing scale 사용

### 4. 모션 디자인
- 이징 커브, 스태거링, reduced-motion 대응
- 의미 있는 애니메이션만 사용

### 5. 인터랙션 디자인
- 폼, 포커스 상태, 로딩 패턴
- 키보드 접근성

### 6. 반응형 디자인
- 모바일 우선, 유동적 디자인, container queries
- 중단점별 레이아웃 전략

### 7. UX 라이팅
- 버튼 레이블, 에러 메시지, 빈 상태
- 명확하고 일관된 UI 텍스트

## 안티패턴 (절대 하지 않을 것)

- Inter 폰트를 기본으로 사용
- 보라색-파란색 그라디언트
- 카드 안에 카드 (과도한 중첩)
- 색상 배경 위의 회색 텍스트
- 의미 없는 장식적 애니메이션
- 모든 요소에 동일한 border-radius
- 대비 없는 폰트 크기 (14px, 15px, 16px이 모두 존재)
