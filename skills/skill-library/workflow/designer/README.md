# Designer (디자이너) 워크플로우

## 이 워크플로우는 무엇인가요?

이 워크플로우는 AI 코딩 에이전트(Claude Code)가 **전문 디자이너처럼** 아름답고 기능적인 인터페이스를 만들도록 돕는 설정 묶음입니다.

[pbakaus/impeccable](https://github.com/pbakaus/impeccable)이라는 오픈소스 프로젝트에서 핵심 내용을 추출했습니다. Impeccable은 "AI가 더 나은 디자인을 하도록 만드는 디자인 언어"입니다.

## 왜 필요한가요?

AI가 생성하는 디자인은 보통 이런 문제가 있습니다:
- 항상 같은 폰트(Inter)를 사용
- 보라색-파란색 그라디언트만 사용
- 카드 안에 카드를 넣는 과도한 중첩
- 색상 배경 위에 읽기 어려운 회색 텍스트
- 모든 웹사이트가 비슷하게 보이는 "AI 느낌"

이 워크플로우는 이런 **"AI 슬롭"(AI가 만든 저품질 디자인)**을 방지하고, 독창적이고 기억에 남는 디자인을 만들도록 합니다.

## 무엇이 들어있나요?

| 파일 | 역할 |
|------|------|
| `CLAUDE.md` | AI에게 전달되는 디자인 원칙, 7대 디자인 도메인, 안티패턴 |
| `settings.json` | Figma, Icons8, SVGMaker MCP 연결 설정 |
| `manifest.yaml` | 이 워크플로우에 포함된 스킬, 에이전트, 명령어 목록 |
| `README.md` | 지금 읽고 있는 이 안내서 |

## 7대 디자인 도메인

이 워크플로우는 디자인을 7가지 전문 영역으로 나누어 가이드합니다:

### 1. 타이포그래피 (글꼴)
어떤 폰트를 쓸지, 크기는 어떻게 정할지, 글자 간격은 얼마로 할지를 정합니다.
- "5단계만 쓰세요" - 너무 많은 크기를 쓰면 계층이 흐릿해집니다
- "Inter 대신 Instrument Sans나 Plus Jakarta Sans를 쓰세요"

### 2. 색상과 대비
색상을 어떻게 선택하고 조합할지를 정합니다.
- OKLCH라는 더 정확한 색상 시스템 사용
- 순수한 회색 대신 브랜드 색조가 살짝 들어간 회색 사용
- 60% 배경 + 30% 보조 + 10% 강조 비율

### 3. 공간 디자인
요소들 사이의 간격과 여백을 일관되게 관리합니다.

### 4. 모션 디자인
화면 전환, 호버 효과 등 움직임을 자연스럽고 의미 있게 만듭니다.

### 5. 인터랙션 디자인
폼, 버튼, 드롭다운 등 사용자가 직접 조작하는 요소를 설계합니다.

### 6. 반응형 디자인
핸드폰, 태블릿, 데스크톱 등 다양한 화면에서 잘 보이도록 합니다.

### 7. UX 라이팅
버튼 텍스트, 에러 메시지, 안내 문구 등 UI의 글을 명확하게 작성합니다.

## 20개 디자인 명령어

이 워크플로우에는 특정 디자인 작업을 수행하는 20가지 명령어가 포함되어 있습니다:

| 명령어 | 간단 설명 |
|--------|----------|
| `/teach-impeccable` | 처음 한 번, 프로젝트의 디자인 방향을 AI에게 알려줍니다 |
| `/audit` | 접근성, 성능, 반응형을 자동으로 검사합니다 |
| `/critique` | 디자인의 장단점을 전문가 관점에서 평가합니다 |
| `/polish` | 출시 전 마지막 다듬기를 합니다 |
| `/bolder` | 밋밋한 디자인을 더 대담하게 만듭니다 |
| `/quieter` | 과한 디자인을 차분하게 조절합니다 |
| `/animate` | 자연스러운 애니메이션을 추가합니다 |
| `/colorize` | 전략적으로 색상을 입힙니다 |
| `/distill` | 불필요한 것을 제거하고 핵심만 남깁니다 |

## 어떻게 사용하나요?

### 방법 1: 프로젝트에 적용 (권장)
```bash
cp workflow/designer/CLAUDE.md .claude/CLAUDE.md
cp workflow/designer/settings.json .claude/settings.local.json
```

### 방법 2: 글로벌 적용
```bash
cp workflow/designer/CLAUDE.md ~/.claude/CLAUDE.md
cp workflow/designer/settings.json ~/.claude/settings.json
```

### 방법 3: Library 명령어 사용
```bash
/library workflow-use designer
```

## MCP 연결 설정

이 워크플로우에는 디자인 도구 연결이 포함되어 있습니다:

| MCP | 역할 | 필요한 것 |
|-----|------|----------|
| **Figma** | Figma 디자인 파일 직접 연동 | Figma 계정 |
| **Icons8** | 아이콘 검색 및 사용 | 없음 (무료) |
| **SVGMaker** | SVG 이미지 생성 | API 키 필요 |

SVGMaker API 키는 settings.json의 `{{SVGMAKER_API_KEY}}`를 실제 키로 교체하세요.

## 주의사항

- 디자인 작업 전 반드시 `/teach-impeccable`로 프로젝트 컨텍스트를 설정하세요
- Figma MCP를 사용하려면 Figma가 열려 있어야 합니다
- 기존 프로젝트의 CLAUDE.md가 있다면, 이 파일의 내용을 기존 파일에 **병합**하세요
