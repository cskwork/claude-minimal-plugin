# Marketer Workflow

> 이 워크플로우를 프로젝트의 `.claude/` 디렉토리에 복사하면 콘텐츠 마케터 중심의 AI 환경이 구성됩니다.

## 핵심 원칙

- **콘텐츠 우선**: 기술보다 메시지가 먼저다
- **데이터 기반**: YouTube, 블로그, SNS에서 트렌드와 인사이트를 수집한다
- **시각적 전달**: 텍스트만으로는 부족하다 - 다이어그램과 시각 자료를 활용한다
- **재사용 가능**: 하나의 콘텐츠를 여러 형태로 변환한다

## 콘텐츠 제작 파이프라인

### 1단계: 리서치 (YouTube 트랜스크립트)
YouTube 영상에서 자막/대본을 추출하여 콘텐츠 소재로 활용합니다.

**사용 방법:**
- YouTube URL을 제공하면 자동으로 트랜스크립트를 다운로드
- 한국어, 영어, 일본어 등 다양한 언어 지원
- 추출된 텍스트에서 핵심 포인트, 인사이트, 인용구를 정리

**활용 예시:**
- 경쟁사 콘텐츠 분석
- 업계 전문가 강연 요약
- 트렌드 키워드 추출
- 블로그 포스트 소재 수집

### 2단계: 시각화 (Excalidraw 다이어그램)
추출한 콘텐츠를 시각적 다이어그램으로 변환합니다.

**지원 형식:**
- **Obsidian (.md)**: Obsidian 노트에 삽입 가능한 Excalidraw
- **표준 (.excalidraw)**: 어디서나 사용 가능한 표준 형식
- **애니메이션 (.excalidraw)**: 프레젠테이션용 순서 있는 다이어그램

**활용 예시:**
- 프로세스 플로우차트
- 마인드맵
- 비교 다이어그램
- 아키텍처 개요도
- 인포그래픽 초안

### 3단계: 콘텐츠 변환
리서치와 시각 자료를 다양한 콘텐츠 형태로 변환합니다:

- **블로그 포스트**: YouTube 영상 내용을 글로 재구성
- **소셜 미디어**: 핵심 인사이트를 짧은 포스트로
- **프레젠테이션**: 다이어그램을 슬라이드 자료로
- **뉴스레터**: 여러 소스를 종합하여 큐레이션

## 콘텐츠 품질 체크리스트

- [ ] 타겟 독자가 명확한가?
- [ ] 핵심 메시지가 3문장 이내로 요약되는가?
- [ ] 시각 자료가 텍스트를 보완하는가?
- [ ] 원본 소스가 명시되어 있는가?
- [ ] 행동 유도(CTA)가 포함되어 있는가?

## 작업 규칙

1. **소스 먼저** - 콘텐츠를 만들기 전에 충분한 리서치를 한다
2. **구조화** - 정보를 논리적으로 구조화한 후 작성한다
3. **시각화** - 복잡한 개념은 다이어그램으로 설명한다
4. **출처 명시** - 모든 인용과 참고 자료의 출처를 밝힌다
5. **반복 개선** - 초안 작성 → 검토 → 수정의 사이클을 반복한다
